Biolinks Commerce — cPanel deployment checklist
=============================================

A) Database
   1. cPanel → MySQL Databases → create database + user
   2. phpMyAdmin → Import → server/mysql-schema.sql

B) Data from Supabase (optional)
   1. Supabase → each table → Export CSV → server/import-data/
   2. server/.env → IMPORT_DEFAULT_PASSWORD=YourTempPassword123
   3. ssh: cd server && npm run import:csv
   4. Tell users to sign in with that temp password and change it

C) Single Node app (recommended)
   1. Local: npm run build:cpanel
   2. Upload entire server/ folder to ~/biolinks-api (exclude node_modules; run npm install on server)
   3. cPanel → Setup Node.js App:
      - Application root: biolinks-api
      - Startup file: src/index.js
      - Node 20+
   4. Environment variables (see deploy/cpanel/env.production.example):
      - STATIC_DIR=/home/USER/biolinks-api/public
      - PUBLIC_URL=https://yourdomain.com
      - CORS_ORIGIN=https://yourdomain.com
      - DB_* and JWT_SECRET
   5. Map domain or subdomain to this app; ensure uploads/ is writable

D) Split frontend + API
   1. npm run build with VITE_API_URL=https://yourdomain.com (or api subdomain)
   2. Upload dist/ to public_html; copy deploy/cpanel/public_html.htaccess → .htaccess
   3. Run API as separate Node app; point VITE_API_URL at it

Verify: https://yourdomain.com/api/health
